ProjectX-Infra is a comprehensive Infrastructure-as-Code (IaC) platform that provisions and manages a full AWS environment in `ap-southeast-2`. Built on Terraform with a layered deployment model, it gives your team a repeatable, auditable, and secure foundation for running containerised workloads on Amazon EKS.

## Key Features

- **Layered Architecture** -- Six logical layers (Network, Storage, IAM, Compute, Analytics, Distribution) that can be planned, applied, and destroyed independently.
- **Docker Workbench** -- A self-contained Ubuntu 22.04 development environment pre-loaded with Terraform 1.5.2, kubectl 1.27.5, Helm 3.12.3, and AWS CLI v2 so every team member works from an identical toolchain.
- **Makefile Orchestration** -- A single `Makefile` exposes every infrastructure operation (`make infra-apply`, `make eks-plan`, `make destroy-all`, etc.) to keep workflows simple and consistent.
- **Multi-AZ Resilience** -- VPC networking spans three Availability Zones with dedicated NAT gateways per AZ, private and public subnet tiers, and Kubernetes-aware subnet tagging.
- **Security by Default** -- Least-privilege IAM roles, Secrets Manager integration, private EKS API endpoints, and encrypted storage at every layer.
- **Cost-Aware Design** -- Spot instance node groups, S3 lifecycle policies, and right-sized RDS instances keep cloud spend under control without sacrificing reliability.
